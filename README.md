## Registro Gimnasio v15

- La cinta de correr incorpora el campo Inclinación (%).
- El cálculo de calorías de la cinta utiliza velocidad, inclinación, tiempo y peso corporal mediante ecuaciones ACSM de marcha/carrera.
- El historial de la cinta muestra también la inclinación registrada.
- El logro de cinta, elíptica y bicicleta estática muestra el mayor tiempo registrado en minutos.
- El logro de las máquinas de fuerza mantiene el récord de peso.
- Se conserva sin cambios el resto de funciones de la v14.
