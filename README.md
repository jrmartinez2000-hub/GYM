## Registro Gimnasio V19.2
- Basada íntegramente en la V19.1 compacta adjunta.
- Agrupa el historial por mes y año mediante acordeones.
- Cada mes indica el número de sesiones, considerando una sesión por cada fecha distinta de entrenamiento.
- Dentro de cada mes se conservan los acordeones diarios, calorías, ejercicios y registros completos.
- Los meses y días se muestran del más reciente al más antiguo.
- Conserva temporizador, pantalla activa, aviso rojo, máquinas, gráficas, Excel, perfiles, fotos y copias JSON.
