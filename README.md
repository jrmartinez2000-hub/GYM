# Registro Gimnasio V28.3

Mantiene la V28.2 e incorpora exclusivamente el acceso «Comenzar ejercicio».

- Identificación por nombre o fotografía con OCR español/inglés.
- Comparación normalizada y aproximada con las máquinas activas del perfil.
- Apertura directa del registro con los últimos datos guardados.
- Selección manual si hay varias coincidencias.
- Si no existe, propone crearla conservando nombre detectado y fotografía.
- Tras crearla desde este flujo abre automáticamente su registro.
