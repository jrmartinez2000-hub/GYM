## Registro Gimnasio V26
- Permite ocultar máquinas conservando historial, calorías, evolución y fotografía.
- Añade Máquinas ocultas en Herramientas avanzadas, con opción de restauración.
- Permite eliminar definitivamente la máquina, su historial vinculado, evolución y fotografía.
- Conserva el resto de funciones y datos de la V25.2.
